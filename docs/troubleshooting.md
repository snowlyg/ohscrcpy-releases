# 故障排查与诊断信息

[返回首页](../README.md)

## 先做四项检查

1. 在“设置 > 更新与日志”确认 ohscrcpy 版本，并使用该版本的程序与文档。
2. 确认 ADB/HDC 能识别目标设备，设备状态不是 `offline`、`unauthorized` 或未连接。
3. 确认设备侧已开启相应调试能力，Windows 防火墙和局域网没有阻断所需连接。
4. 只对视频兼容问题尝试切换 H.264/H.265、清晰度或 OpenHarmony 截图模式；键盘、剪贴板或 WebDebug 故障不应通过反复重启投屏来处理。

## 常见现象

| 现象 | 建议 |
| --- | --- |
| 设备列表看不到设备 | 检查设置中的 ADB/HDC 路径，再用相应命令行工具确认设备状态。 |
| 设备在线但无法开始远程 | 查看 Runtime logs 中的 shell、上传、端口转发、服务端启动和首帧阶段，确认失败发生在哪一步。 |
| 有连接状态但没有画面 | 等待首帧超时信息；OpenHarmony 可尝试截图模式，或切换编解码器和清晰度。 |
| 画面方向不适合窗口 | 使用本地旋转；该操作不会改变设备端采集方向。 |
| 键盘、剪贴板或 WebDebug 不可用 | 将其作为独立可选功能排查；先确认视频会话仍然正常，不要因可选功能失败反复重启投屏。 |
| 更新失败 | 检查更新源网络、ZIP 下载完整性和 SHA-256；也可手动下载 ZIP 后校验并解压。 |

## 导出诊断信息

远程会话启动失败时，使用界面的“导出诊断包”生成脱敏诊断 ZIP。提交问题时建议包含：

- ohscrcpy 版本和 Windows 版本；
- 设备平台（OpenHarmony 或 Android）和连接方式（USB 或局域网）；
- 可重复的操作步骤、期望结果与实际结果；
- 界面导出的脱敏诊断 ZIP；
- 如确有必要，提供经过逐区域检查的截图。

不要提交账号、密码、Token、私钥、真实 IP/MAC/Serial、人员信息、业务记录、通知内容或未脱敏设备画面。模糊和马赛克可能被放大或逐帧推断，公开材料应使用完全不透明遮罩。
